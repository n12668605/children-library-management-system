# Children's Library Management System

## Project Overview

The Children's Library Management System is a web-based application designed to support the management of children's library resources, members, and reservations. The system provides functionality for browsing books, managing member accounts, reserving books, and administering library operations through a user-friendly interface.

This project was developed as part of IFQ636 – Software Lifecycle Management.

## Features

### Member Functions

* Browse and search books
* View book information
* Reserve available books
* Manage library account information

### Administrator Functions

* Add, edit, and delete books
* Manage member accounts
* View and manage reservations
* Monitor library activity

## System Architecture

The application follows a client-server architecture consisting of:

### Frontend

* React
* Vite
* JavaScript
* CSS

### Backend

* Node.js
* Express.js
* REST API architecture

## Installation

### Backend

```bash
cd childrens-library-backend
npm install
npm start
```

### Frontend

```bash
cd childrens-library-frontend
npm install
npm run dev
```
